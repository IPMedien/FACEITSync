# FACEITSync – Automated Twitch Predictions for FACEIT Streamers

FACEITSync is a Twitch & FACEIT integration tool that automates predictions, connects match data in real time, and shows live ELO stats on stream.

**Used daily by pro and former pro CS2 players** such as Tizian , redcs, Olofmeister, tazg5, freeze, and others.

## Features
- Automatic Twitch Predictions for FACEIT matches  
- Real-time ELO & Match Stats Overlay  
- Twitch Chat Integration (`!elo`, `!clip`)  
- Automatic Prediction Resolution  
- Multi-language Support (EN, DE, FR, RU, e.g)  
- Web Dashboard for Streamers

## How it works
1. Log in with Twitch & FACEIT  
2. FACEITSync detects your live match automatically  
3. Twitch predictions start instantly and resolve after the game  
4. Manage everything in your browser dashboard
